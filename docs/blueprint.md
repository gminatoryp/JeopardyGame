# **App Name**: Jeopardy Scoreboard

## Core Features:

- Score Tracking: Display two team names and their scores, with the ability to increment or decrement each team's score.
- Question Selection Status: Visually indicate which questions have already been selected.  Warn if selected again.
- Game Board Display: A customizable game board layout that can be populated with questions and point values

## Style Guidelines:

- Primary color: Blue (#2563eb) for the header and main elements.
- Secondary color: Gray (#6b7280) for the question boxes.
- Accent: Yellow (#facc15) to highlight the selected question and active elements.
- Clean and readable font for the score display and team names.
- Grid layout for the questions and point values.
- Clear separation of the scoreboard and the game board.
